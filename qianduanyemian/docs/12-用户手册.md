# 用户手册
## 深地智控 · 煤矿顶板灾变智能预警与可视化决策系统

| 项 | 内容 |
|---|---|
| 版本 | v1.0 |
| 日期 | 2026-09-14 |
| 适用对象 | 企业端值班员 / 监管调度员 / 智库研究员 / 鸿蒙端用户 |

## 1. 登录与门户
1. 浏览器打开系统首页（`index.html`），输入验证码、账号密码。
2. 测试账号：`mine_super / 123456`（企业端）、`s_admin / 123456`（监管端）、`t_admin / 123456`（智库端）。
3. 登录后进入首页门户，按角色点击对应卡片进入各自看板；登录失败需重新获取验证码，连续失败会短暂锁定（1 分钟）。

## 2. 企业端
- **传感器总览**：查看全部传感器实时值、状态、阈值；卡片标有「高于/低于阈值预警」方向说明。
- **阈值配置**：正式修改入口在此（点击设置），修改立即生效并写审计；注意超声波测距为「值低于阈值」预警，其余为「高于」。
- **预警处置**：查看未处置预警列表与数量，对预警执行「处置/清除」，处置留痕可查。
- **趋势**：查看传感器历史曲线（如顶板压力 24 小时）。

## 3. 监管端
- **监管概览**：矿井列表与运行状态总览。
- **派单下发**：面向矿井创建应急调度（标题/级别/内容/目标矿井），状态流转 PENDING → IN_PROGRESS → 完成。
- **审计查看**：仅监管端可查看全系统审计日志（/api/audit）。

## 4. 智库端
- **模型指标**：查看数字孪生 AI 模型精度等指标。
- **风险分析**：趋势/威胁评估/统计。
- **报告**：查看报告列表；智库角色可生成/导出分析报告。

## 5. 综合态势大屏
- **进入方式**：登录后从任意三端页面侧边栏「综合态势大屏」进入（首页不直接展示）。
- **图层与点位**：切换地质/云图/巷道等图层；点击传感器点位查看详情与融合信息。
- **预警弹窗**：出现预警时弹窗展示级别、数值、阈值与方向；预警光晕随级别变色（红/橙/黄）。
- **滑杆演示**：拖动阈值滑杆仅作本地演示（界面提示"不保存，刷新后恢复"），不影响正式阈值；正式修改请回企业端。

## 6. 鸿蒙客户端
- 模拟器调试：后端地址用 `10.0.2.2:3000`；真机用 PC 的局域网 IP（同 WiFi/热点）。
- 支持登录、三端看板、传感器详情、VR 场景、协同闭环等页面。

## 7. STM32 硬件接入（MQTT）
1. PC 开热点（或连同一路由器），`ipconfig` 查 PC 局域网 IP。
2. 设备 WiFi 连该热点；固件配置 broker 为 `<PC IP>:1883`，主题 `sensor/<sensorId>/data`。
3. 载荷支持：纯数值 `12.5`、`{"value":12.5}`、`{"sensorId":"x","value":12.5}`。
4. 后端需按 docs/05 在 server.js 接线启动 mqtt-bridge；PC 端可用 `mosquitto_sub` 验证主题消息。

## 8. 常见问题速查（详见 docs/09-运维手册.md）
| 问题 | 处理 |
|---|---|
| 无法连接服务器 | 后端未启动，运行 start-backend.bat / start.sh |
| 页面改动不生效 | 刷新并清除缓存；确认脚本 `?v=` 版本号已更新 |
| 大屏阈值调了又恢复 | 属演示模式（本地临时），正式修改走企业端阈值配置 |
| 设备数据不上屏 | 检查热点连通、broker 端口 1883、主题与载荷格式 |
