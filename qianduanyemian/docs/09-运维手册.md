# 运维手册
## 深地智控 · 煤矿顶板灾变智能预警与可视化决策系统

| 项 | 内容 |
|---|---|
| 版本 | v1.0 |
| 日期 | 2026-09-14 |
| 适用范围 | Windows（演示/开发）与 Deepin（部署）双环境 |

## 1. 架构与端口

```
PC 前端（index/enterprise/supervision/thinktank/bigscreen）  ┐
鸿蒙客户端                                                    ├─► HTTP :3000（后端 API）
                                                             ├─► WS   :8080（实时广播）
STM32 / 模拟器 ──MQTT──► Broker :1883 ──► mqtt-bridge ────────┘
后端依赖：PostgreSQL :5432、Redis :6379（会话/限流，可降级）
可选：HTTPS :8443（自签证书）、PM2 守护（ecosystem.config.js）
```

## 2. 环境要求
- Node.js ≥ 18（含 npm）
- PostgreSQL ≥ 12（库名/账号见 .env）
- Redis ≥ 6（无 Redis 时后端按降级模式运行）
- MQTT Broker（EMQX / Mosquitto）——可选，STM32 接入时必需

## 3. 部署启动

### 3.1 Windows（演示开发）
1. 配置 `backend/.env`（数据库连接、端口）。
2. 初始化数据库：`npm run db:setup`（backend 目录）。
3. 一键启动：运行 `qianduanyemian/start-backend.bat`（含 DB 连接 + 后端 + WS + 模拟器 + MQTT 桥接）。

### 3.2 Deepin（部署环境）
1. 使用 Linux 原生脚本（不要用 .bat）：`setup-db.sh` 初始化库，`start.sh` 启动服务。
2. 前端资源中的 Google Fonts 依赖已替换为系统字体（Noto Sans CJK SC / 文泉驿），无外网可用。

### 3.3 生产（PM2）
```
cd backend
npm ci
pm2 start ecosystem.config.js     # 守护 + 自动重启
pm2 save && pm2 startup           # 开机自启
```

### 3.4 HTTPS（可选）
```
node scripts/generate-selfsigned-cert.js     # 生成 certs/*.pem
# .env 中 HTTPS_ENABLED=true、REDIRECT_HTTPS=true 后重启
```

## 4. 配置清单（backend/.env）
| 变量 | 默认 | 说明 |
|---|---|---|
| PORT | 3000 | HTTP 端口 |
| WS_PORT | 8080 | WebSocket 端口 |
| MQTT_URL / MQTT_HOST | mqtt://localhost | broker 地址（MQTT_PORT 1883） |
| MQTT_TOPIC | sensor/+/data | 上行订阅主题 |
| DATABASE_URL / PGHOST 等 | localhost | PostgreSQL 连接 |
| REDIS_URL | redis://localhost | Redis 连接 |
| NODE_ENV | development | 运行环境 |
| HTTPS_ENABLED / HTTPS_PORT | false / 8443 | HTTPS 开关与端口 |

**注意**：`.env` 含真实凭据，已加入 .gitignore，请勿提交；克隆/部署后以 `.env.example` 为模板新建。

## 5. 数据库
- 初始化：`npm run db:setup`
- 备份：`node scripts/backup-db.js`（输出到 backend/backups/，该目录不入库）
- 恢复：使用备份文件的 pg_restore/psql 导入，恢复前先停后端
- 表：sensors、alert、sensor_history、users、sessions 等（见 sjk/schema.sql）

## 6. 监控与告警
- 一键检查：`npm run monitor`（= `node scripts/monitor.js`），检查 HTTP/WS/MQTT/PG 四项，全部正常退出码 0，任一异常 1。
- 循环监控：`npm run monitor -- --loop 10`（每 10 秒，Ctrl+C 退出）。
- 定时告警接入：
  - Windows：任务计划程序 → 创建任务 → 操作 `cmd /c "npm run monitor --prefix <backend> || echo 服务异常 >> monitor.log"`，按需每 5 分钟执行。
  - Deepin：crontab `*/5 * * * * cd <backend> && node scripts/monitor.js || logger -t coal-guard "服务异常"`。
- 人工核查：浏览器访问 `http://localhost:3000/api/health`、`/api/health/detailed`。

## 7. 日志与备份
- 后端请求日志：morgan 输出到控制台；审计日志入库（/api/audit）。
- 数据备份：backups/ 目录；建议每日执行 backup-db.js。
- 前端发布：修改 HTML 中脚本版本号（如 `?v=20260914`）强制客户端刷新，避免缓存旧脚本。

## 8. 常见故障排查
| 现象 | 原因与处理 |
|---|---|
| 「无法连接到服务器」 | 后端未启动 → 运行 start-backend.bat / start.sh |
| 页面修改不生效 | 浏览器缓存旧脚本 → 升级 `?v=` 版本号后刷新 |
| 大屏阈值调完又变 / 不保存 | 属演示模式：滑杆仅本地临时，刷新恢复；正式修改请走企业端阈值配置 |
| 字体加载失败（Deepin） | 无外网时 Google Fonts 不可用，已用系统字体替代 |
| MQTT 设备数据不上屏 | broker 未启动 / 主题不符 / .env 未配 → 见 docs/05 |
| 登录提示验证码错 | 失败后需重新获取验证码；连续失败触发 5 次/分钟锁定 |
| 鸿蒙端连不上 | 模拟器用 10.0.2.2:3000，真机用 PC 局域网 IP，且保证后端已启动 |
| DB 连接失败 | 检查 PostgreSQL 服务与 .env 凭据；`npm run db:setup` 重建结构 |

## 9. 变更与发布流程
1. 改代码 → 本地跑 `npm test` 全绿；
2. 前端改版 → 更新 `?v=` 版本号；
3. `git add` + `git commit`（仓库基线见 .gitignore，`.env`/依赖/Deepin 副本不入库）；
4. 生产环境：`git pull` + `pm2 reload`，必要时 `npm run monitor` 验证。
