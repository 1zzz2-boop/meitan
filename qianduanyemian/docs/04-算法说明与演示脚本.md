## 二、关键算法说明

### 2.1 预警阈值判定算法（后端 `sensor.service.js`）

系统对顶板灾变采用**阈值偏离比 + 分级预警**判别。要点：超声波测距（顶板下沉）**值越小越危险**（判向 `<`），其余传感器**值越大越危险**（判向 `>`）。

```javascript
// 预警阈值判定：ULTRASONIC_DISTANCE 值 < 阈值 预警；其余值 > 阈值 预警
function isOverThreshold(sensor) {
    if (sensor.threshold === null || sensor.threshold === undefined) return false;
    if (sensor.type === 'ULTRASONIC_DISTANCE') return sensor.value < sensor.threshold;
    return sensor.value > sensor.threshold;
}

// 分级判定：按偏离阈值比例划分 黄/橙/红 三级
function alertLevelOf(sensor) {
    if (!isOverThreshold(sensor)) return null;
    const ratio = Math.abs(sensor.value - sensor.threshold) / sensor.threshold;
    if (ratio > 0.5) return 'RED';      // 红色预警：超阈值 50% 以上
    if (ratio > 0.3) return 'ORANGE';   // 橙色预警：超阈值 30% ~ 50%
    return 'YELLOW';                    // 黄色预警：刚越过阈值
}
```

**算法特点**：单一函数统一处理两类判向（顶板下沉为反向阈值），分级阈值与《平台系统设计方案》中的指标表一一对应，保证多端判定逻辑一致。

### 2.2 威胁度占比与风险指数（后端 `analysis.service.js`）

智库端将传感器当前值归一化为**威胁度百分比**，供大屏/智库端可视化：

```javascript
// 威胁度：当前值 / 阈值（超声波为反向计算），截断到 0~100%
let pct = s.type === 'ULTRASONIC_DISTANCE'
    ? (s.threshold - s.value) / s.threshold
    : s.value / s.threshold;
pct = Math.max(0, Math.min(100, Math.round(pct * 100)));
```

风险指数融合"未处置预警数"动态计算：`risk = clamp(42 + 未处置数 × 6, 8, 98)`，体现预警处置闭环对整体风险的影响。

### 2.3 预警模型算法（MCFLR 多场耦合融合逻辑回归，后端 `model.service.js`）

模型指标由真实算法**训练评估产出**（非写死数值）：机理数据（文献参数标定）+ 真实历史数据 → 特征工程 → 纯 JS 类别加权逻辑回归 → 测试集评估 → 结果持久化到 `model_state` 表，数据增长自动重训，智库端可一键重训。

**（1）特征工程（13 维）**：5 场威胁度（顶板下沉取反）+ 5 场变化趋势 + 多场耦合强度 + 耦合广度 + 近5点累积异常。先按时间顺序抽取时序特征（趋势/累积依赖前后样本），再固定种子洗牌切分 75/25。

**（2）类别加权逻辑回归（纯 JS 实现）**：正/负样本权重 `n/(2·正) / n/(2·负)` 缓解不平衡，L2 正则 + 600 轮梯度下降：

```javascript
function trainLR(X, y, dim, epochs = 600, lr = 0.5, lambda = 0.001) {
    const n = X.length, pos = y.reduce((a, b) => a + b, 0), neg = n - pos;
    const wp = n / (2 * pos), wn = n / (2 * neg);          // 类别权重
    let w = new Array(dim).fill(0);
    for (let e = 0; e < epochs; e++) {
        const grad = new Array(dim).fill(0);
        for (let i = 0; i < n; i++) {
            let z = 0;
            for (let j = 0; j < dim; j++) z += w[j] * X[i][j];
            const wi = y[i] === 1 ? wp : wn;
            const err = (sigmoid(z) - y[i]) * wi;
            for (let j = 0; j < dim; j++) grad[j] += err * X[i][j];
        }
        for (let j = 0; j < dim; j++) {
            const reg = j === 0 ? 0 : lambda * w[j];       // 偏置不惩罚
            w[j] -= lr * (grad[j] / n + reg);
        }
    }
    return w;
}
```

**（3）工作点选择（安全优先）**：阈值扫描 0.15~0.85 → 在**召回率 ≥88%** 前提下选误报率最低的阈值，并列取准确率更高——宁可多预警也不漏报危险事件。

**（4）系统实测评估（测试集 N=720）**：

| | 预测预警 | 预测正常 |
|---|---|---|
| **实际预警** | TP = 22 | FN = 3 |
| **实际正常** | FP = 9 | TN = 686 |

- 准确率 = (22+686)/720 = 98.3%
- 召回率 Recall = 22/(22+3) = 88.0%
- 误报率 = 9/(9+686) = 1.3%
- F1 = 2×71.0×88.0/(71.0+88.0) ≈ 78.6%

**阈值-准确率/误报率曲线**（供预警阈值选优）：工作点阈值 0.70 时准确率 98.3%、误报率 1.3%，兼顾"早发现"与"少误报"；曲线与混淆矩阵在智库端可视化呈现。

### 2.4 多场耦合云图联动算法（前端 `bigscreen.js`）

按压传感器点位时，与其物理场关联的云图（应力/位移/水压）按倍率**实时扩张**并高亮，松开后恢复原尺寸，直观展示"应力 → 位移 → 水压"多场耦合传导：

```javascript
function boostClouds(sid, on) {
    const s = SENSORS[sid];
    const cfg = s && FIELD_BOOST[s.type];   // 传感器类型 → 关联场配置
    if (!cfg) return;
    svg.querySelectorAll('.cloud').forEach(c => {
        const f = c.dataset.field;
        if (!cfg.fields.includes(f)) return;   // 仅扩张本传感器关联的场
        const factor = cfg.factor;
        if (on) {                              // 按压：按倍率扩张 + 高亮
            c.dataset.origR = c.getAttribute('r');
            c.setAttribute('r', (+c.dataset.origR * factor).toFixed(1));
            c.classList.add('hot');
        } else {                               // 松开：恢复原尺寸
            if (c.dataset.origR) c.setAttribute('r', c.dataset.origR);
            c.classList.remove('hot');
        }
    });
}
```

### 2.5 按住爬升 / 松开回落 交互算法（前端 `bigscreen.js`）

长按 400ms 进入"爬升态"，按 300ms 周期递增（超声波为递减），越限截断；松开进入"回落态"，按 `diff/8` 指数趋近基线，误差 <0.05 时复位。期间每 1200ms 将当前值写回后端并广播，实现三端联动：

```javascript
function startClimb(p) {
    demo.base = s.value; demo.cur = s.value;
    demo.phase = 'climbing';
    boostClouds(p.sid, true);               // 关联云图扩张
    demo.timers.push(setInterval(() => {    // 爬升步进 300ms
        demo.cur += demo.rate * demo.dir;   // dir=+1 上升 / dir=-1 下沉
        if (cfg.max != null && demo.cur > cfg.max) demo.cur = cfg.max;
        SENSORS[demo.sid].value = demo.cur;
        pushHistory(demo.sid, demo.cur);    // 写入历史
        renderScene(); renderKpi();         // 实时刷新场景与指标
    }, 300));
    demo.timers.push(setInterval(syncDemoToDB, 1200));   // 同步后端 → 广播
}
function stopClimb() {
    demo.phase = 'recovering';
    boostClouds(demo.sid, false);           // 云图逐步恢复
    demo.timers.push(setInterval(() => {    // 回落步进 500ms
        const diff = demo.base - demo.cur;
        if (Math.abs(diff) < 0.05) { demo.cur = demo.base; finishDemo(); return; }
        demo.cur += diff / 8;               // 指数趋近基线（先快后慢）
    }, 500));
}
```

各演示传感器参数（`DEMO_TYPES`）：薄膜压力 0.60/步（上限 32kN）、水压 0.06/步（上限 2.5MPa）、震动 0.06/步（上限 1.2g）、锚杆应变 0.008/步（上限 0.12mm）、超声波下沉 0.06/步（下限 0.2m）。

### 2.6 三端实时联动（WebSocket 广播）

任何一端写入传感器数据后，后端 `sensor.controller.js` 立即拉取全量传感器并广播：

```javascript
await sensorService.updateSensorData(sensorId, value);   // 写库
const all = await sensorService.getAllSensors();
wsHub.emit('sensor_update', all);                        // 广播给所有已连接端
```

鸿蒙端、PC 三端、大屏订阅 `sensor_update` 事件后刷新各自视图，形成"一端操作、多端同屏"的实时联动效果。

### 2.7 地质素描关联判别

点击场景中断层 F₁ / 溶洞 / 含水层等地质要素，弹出地质素描信息卡（构造类型、构造性质、灾变关联、地质素描文字），将物理力学机理（2.1 节判别依据）落到可交互的建模场景上。
