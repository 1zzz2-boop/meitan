## 1. 引言

### 1.1 目的
本文档定义系统已实现功能的需求基线，作为设计、开发、测试与验收的对照依据。需求均以当前代码实现为准（实然需求），并给出验收标准（DoD）与追踪矩阵。

### 1.2 术语
- **三端**：企业端（enterprise）、监管端（supervision）、智库端（thinktank）三种角色的 PC 门户。
- **大屏**：综合态势大屏（bigscreen），登录后从三端侧边栏进入。
- **鸿蒙端**：HarmonyOS 客户端（ArkTS）。
- **传感器类型**：超声测距（ULTRASONIC_DISTANCE，值**低于**阈值预警）与压力/应力/位移/振动等（值**高于**阈值预警）。

## 2. 系统概述

### 2.1 角色
| 角色 | 说明 |
|---|---|
| enterprise | 企业端：矿井监测、阈值配置、预警处置 |
| supervision | 监管端：监管概览、派单下发 |
| thinktank | 智库端：模型指标、分析报告 |

### 2.2 组成模块
登录认证、首页门户、企业端、监管端、智库端、综合态势大屏、后端 API、WebSocket 实时广播、数据模拟器、MQTT 桥接、鸿蒙客户端、数据库（PostgreSQL + Redis）。

## 3. 功能需求

### 3.1 认证与账号（FR-AUTH）
| ID | 需求 | 验收标准（DoD） |
|---|---|---|
| FR-AUTH-01 | 图形验证码获取 | GET /api/auth/captcha 返回 id+图片；同 IP 限 30 次/分钟 |
| FR-AUTH-02 | 账号密码+验证码登录 | 校验通过返回 token 与角色；失败统一 401 且需重新取验证码；账号 5 次/分钟、IP 20 次/分钟限流，超限 429 |
| FR-AUTH-03 | 注册 | 成功 201；重名/非法角色 409 |
| FR-AUTH-04 | 修改密码 | 返回 200+success 标志，便于鸿蒙端直接展示中文提示 |
| FR-AUTH-05 | 会话鉴权 | 业务接口需 Authorization: Bearer token；无效会话 401 |
| FR-AUTH-06 | 角色鉴权 | 越权访问返回 403（企业端调监管接口等） |

### 3.2 门户与三端页面（FR-UI）
| ID | 需求 | 验收标准（DoD） |
|---|---|---|
| FR-UI-01 | 首页门户 | 登录后展示三端卡片入口；综合态势大屏不直接展示于首页 |
| FR-UI-02 | 企业端 | 传感器总览/预警处置/阈值配置/趋势，显示「高于/低于阈值预警」方向 |
| FR-UI-03 | 监管端 | 矿井概览、派单下发与状态更新 |
| FR-UI-04 | 智库端 | 模型指标、风险分析、报告导出 |
| FR-UI-05 | 大屏 | 登录后经三端侧边栏进入；支持图层/点位交互、演示调节（本地不落库） |

### 3.3 数据与预警（FR-DATA）
| ID | 需求 | 验收标准（DoD） |
|---|---|---|
| FR-DATA-01 | 传感器数据 | GET /api/sensor/all、/stats、/thresholds、/type/:type、/:id |
| FR-DATA-02 | 手动更新传感器 | POST /api/sensor/update 立即广播到所有 WS 客户端 |
| FR-DATA-03 | 阈值配置 | POST /api/sensor/thresholds（enterprise/supervision）；大屏滑杆仅本地演示不落库 |
| FR-DATA-04 | 预警列表 | GET /api/alert/all、/unhandled、/unhandled/count |
| FR-DATA-05 | 预警处置 | POST /api/alert/handle、/clear（enterprise/supervision） |
| FR-DATA-06 | 阈值方向 | 超声测距值<阈值预警；其余值>阈值预警，界面明示方向 |

## 4. 非功能需求（NFR）
| ID | 需求 | 指标/约束 |
|---|---|---|
| NFR-01 | 性能 | 接口响应 < 500ms（单机演示环境）；WS 广播延迟 < 1s |
| NFR-02 | 安全 | 登录验证码+双因子限流；业务接口全部鉴权；敏感操作留审计；Helmet 安全头；.env 不入库 |
| NFR-03 | 兼容 | Windows（start-backend.bat）与 Deepin（start.sh/setup-db.sh）；页面资源带 ?v= 版本号防缓存 |
| NFR-04 | 可用性 | 数据模拟器与 MQTT 桥接失败不阻塞主服务；桥接自动重连 |
| NFR-05 | 可维护性 | 单元/集成测试 36 用例全绿；代码规范（无 lint 基线，见测试报告遗留项） |

## 5. 验收标准汇总（DoD）
见 3.x 各表「验收标准」列；整体验收条件：
1. `npm test` 全部通过；
2. 三端登录后能访问各自看板，大屏可从三端侧边栏进入；
3. WS 客户端能实时收到传感器/预警广播；
4. 越权请求返回 403，未登录返回 401；
5. 大屏阈值演示调节刷新后恢复，不污染正式阈值。
