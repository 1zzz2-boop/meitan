## 7. 遗留问题与建议
| 级别 | 问题 | 建议 |
|---|---|---|
| 中 | 无代码覆盖率统计 | 引入 jest --coverage，目标核心服务 ≥ 70% |
| 中 | 前端零自动化测试 | 对 app.js 关键函数（thresholdDir/预警分级）补轻量单测 |
| 低 | 无标定传感器分支无量程边界（统计上有界，理论可漂移） | 演示数据不依赖；如需可加均值回归锚定 |
| 低 | 登录接口 /api/auth/change-password、register 为公开路由 | 评审是否需要登录后才能改密 |
| 低 | 无 ESLint/Prettier 基线 | 纳入 CI 前的规范步骤 |
